MMSBM (Mixed Membership Stochastic Block Models) is a Python library for 
efficient recommendation systems using stochastic block modeling.

Since version 1.1 it also includes a degree-corrected variant of the model,
which additionally explains which user-item pairs are observed, and a
cross-validated procedure to choose the number of groups. See
:doc:`theory/mmsbm` and :doc:`guides/quickstart`.
